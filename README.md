🌀 Collatz Conjecture Explorer

An interactive web application to explore the Collatz conjecture through visualizations and simple statistics.
This app allows users to:
- Visualize the Collatz trajectory of a single natural number
- Study the distribution of stopping times for a range of numbers
- Interact with the conjecture directly in the browser (no installation required)

🔢 What is the Collatz Conjecture?

The Collatz conjecture states that for any positive integer n:
- If n is even → divide it by 2
- If n is odd → multiply it by 3 and add 1
- Repeating this process is conjectured to eventually reach 1 for all positive integers.

Despite its simplicity, this problem remains unsolved.

🚀 Features
1. Single Number Trajectory
Enter any integer n > 1
- View its full Collatz sequence
- Plotted on a logarithmic scale to handle large values clearly

2. Step Frequency Analysis

- Select a range of integers (e.g. 2 to 100)
- Compute how many steps each number takes to reach 1
- Visualized as a frequency histogram

3. Fully Interactive
- Runs in the browser
- Compatible with desktop and mobile
- No setup required for users
